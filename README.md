# Chochos Recipes

Step 1 scaffold for a modular multi-page Recipes app.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Supabase client

## Structure

- Header component
- Footer component
- Home page (currently empty)
- Route-based multi-page setup
